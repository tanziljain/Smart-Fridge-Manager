# 🧊 Smart Fridge Manager & AI-Based Recipe Generator 🍲  
### A Complete IoT + AI Powered Kitchen Assistant  

The **Smart Fridge Manager** is an integrated system that combines **IoT-based ingredient monitoring** with a **web-based AI recipe generator**.  
It helps users track fridge inventory, detect spoilage, monitor environmental conditions, and automatically suggest recipes using available ingredients.

This project reduces food wastage, saves time in cooking, and creates a seamless kitchen-automation experience.

---

## 🚀 Key Features  

### 🟦 **IoT Hardware Module (Smart Food Storage Monitor)**  
- Uses **ESP8266 / NodeMCU**  
- **DHT11 Sensor** → Temperature & humidity monitoring  
- **MQ-3 Gas Sensor** → Spoilage / contamination detection  
- Sends real-time data to the web app  
- LCD display for fridge-side updates  
- Alerts for spoilage, high temperature, or humidity drift  

---

### 🟩 **Web Application Features**  
Built using **HTML, CSS, JavaScript** (separate folders maintained).

#### 🥕 **Smart Inventory Manager**  
- Add, edit, delete food items  
- Track quantities & expiry dates  
- Automatic update from IoT sensor data  
- Indicators for items nearing expiry  
- Colour-coded freshness status  

#### 🤖 **AI-Based Recipe Generator**  
- Suggests recipes using available ingredients  
- Uses the **Spoonacular API** for recipes + nutritional breakdown  
- Options for veg, vegan, high-protein, low-fat, keto, etc.  
- Users can save recipes for later  
- “Download Recipe as PDF” feature included  

#### 🗂️ **Meal Planner & Shopping List**  
- Weekly meal planner  
- Auto-add missing ingredients to shopping list  
- Smart suggestions based on fridge data  

#### 📊 **Analytics Dashboard**  
- Usage patterns  
- Food wastage reports  
- Recipe trends  
- Ingredient consumption frequency  

#### 🌓 **Dark Mode**  
Full dark/light theme toggle.

#### 🏅 **Healthy Habit Badge System**  
Automatically awards badges based on:  
- Low-fat recipes  
- Balanced meals  
- High protein intake  
- Consistent weekly planning
